# Student Learning Management App

## Project Overview

The Student Learning Management App is a full-stack Flask web application designed to help students stay organized and improve productivity.

This application allows users to:

- Create and manage academic tasks
- Write and publish blog posts
- Upload and organize study notes/images
- Securely register and log in to personal accounts

The app was developed using Flask, SQLite, HTML, CSS, and Bootstrap.

---

# Features

## User Authentication
- User registration
- User login/logout
- Password hashing using Werkzeug
- Protected routes using Flask-Login

## Task Management System
- Add tasks
- View tasks
- Mark tasks as completed
- Delete tasks
- Task categories
- Task timestamps

## Blog System
- Create blog posts
- View blog posts
- Delete blog posts
- Blog timestamps

## Notes Upload System
- Upload note images
- Store uploaded files in static/uploads
- View uploaded notes
- Delete uploaded notes
